

 Lab Session 2: Control Flow, Enums & Option

This directory contains the solutions for **Lab Session 2**, focusing on pattern matching, custom enumerations, handling nullability safely using `Option`, and basic mathematical operations.

## 📝 Exercises & Implementation Details

* **Exercise A — Pattern Matching with `match`:** 
  Examines exhaustive matching across integer ranges and custom status values.
* **Exercise B — Custom Enums:** 
  Defines custom `enum` types carrying underlying data variants and matching on them.
* **Exercise C — The `Option` Enum:** 
  Demonstrates safe error handling without null pointers using `Option::Some` and `Option::None`.
* **Exercise D — Heron's Formula:** 
  Implements triangle area calculations based on side lengths, safely handling invalid side dimensions.
